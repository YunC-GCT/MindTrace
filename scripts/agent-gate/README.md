# scripts/agent-gate/

One command that answers: **“is this change safe to hand off?”**

It is the entry point for AI coding agents (and humans) before claiming a task is done.

## Usage

```bash
node scripts/agent-gate/index.mjs          # current change set (tracked + untracked)
node scripts/agent-gate/index.mjs --all    # whole repo
node scripts/agent-gate/index.mjs --json   # machine-readable result
```

Exit codes: `0` pass, `1` at least one error, `2` setup error.

## What it checks

| Check | Scope | Failure |
|---|---|---|
| `ets-hygiene` | changed `.ets` files | UTF-8 BOM; `agents/` importing `entry/`; pages/overlays importing `CaptureGraph`, `Dispatcher`, or `NoteDao` directly |
| `arkts-lint` | whole repo, only when `.ets` changed | any lint **error** (warnings are reported but do not fail) |
| `naming-lint` | `docs/` + `scripts/` | naming violation |
| `link-check` | markdown roots | broken relative link |
| `doc-trace` | `docs/` | unreachable doc, incomplete index, duplicate spec/ADR number |

Warnings (e.g. a missing `.ets` file header) are printed but do not fail the gate. The file-header convention is in `docs/agents/file-header-template.md`.

## Rule source

- Human-readable rules: `docs/style/arkts-1.1.md`
- 60-second checklist: `docs/style/arkts-ai-coding.md`
- Machine-readable rule list: `docs/style/arkts-rules.json` (generated by `node scripts/arkts-lint/export-rules.mjs`)
