## 0. 这份文档要解决什么

上一版架构图被旧仓库的模块划分带偏了：把 `entry / agents / common` 三个代码模块当成了架构分层，还画了一个只存在于设计稿里的 `AgentFacade`。结果图上是“旧项目长什么样”，不是“这次系统要做成什么样”。

这份文档重新回答三个问题：

1. 系统分几层，每层负责什么
2. 一次“小艺说一句话 → 笔记进库”到底经过谁
3. 图上该画哪些框、哪些线

## 1. 上一版图错在哪

| # | 错误 | 为什么错 |
|---|---|---|
| 1 | 用 `entry / agents / common` 当边界 | 这是代码目录，不是系统分层。新架构按“入口—编排—执行—资产”切 |

| 3 | 画了 `AgentFacade` | 上一轮的内部分层设计，未落地，也不该出现在系统图 |

| 6 | 没有“智能体”这一层 | 接入小艺开放平台后，编排发生在上层，图里缺了这一整层 |

## 2. 设计原则

1. **入口在系统，执行在应用。** 小艺拿到语音和意图，真正读图库、跑 OCR、写库的是应用进程。端插件本质是拉起 Ability，不是云端直连本地数据。
2. **App 只当资产容器。** 笔记、复习计划、知识星系是它的全部职责；生成逻辑不在 App 里。
3. **能力按来源分层，不按代码模块分层。** Kit（端侧系统能力）/ MCP（模型与服务）/ 应用自有逻辑，三者边界清楚。
4. **一条主链路先跑通。** 多入口、多场景都往后排。

---

## 3. 新分层（4 层）

| 层 | 名字 | 里面有什么 | 职责 |
|---|---|---|---|
| L1 | 系统入口层 | 小艺语音、系统搜索、卡片 | 接住用户的一句话，识别意图 |
| L2 | 智能体层 | 小艺智能体（意图理解、任务规划、插件调用） | 决定“要做什么、调哪个能力、按什么顺序” |
| L3 | 端能力层 | 应用里的意图 Ability、批处理队列、图库适配、OCR 适配、生成适配 | 真正干活：选图、识别、生成、落库 |
| L4 | 资产层 | RDB（笔记/复习计划）、知识星系、语义索引 | 存住用户的知识财产，供展示与检索 |

一句话：**L1 接话，L2 想事，L3 干活，L4 存钱。**

---

## 4. 主链路

```
用户对小艺说「把相册里的数学题整理成笔记」
  → L1 小艺识别意图
  → L2 智能体规划：需要「选图 → 识别 → 生成 → 落库」四步
  → L3 端插件拉起应用 Ability
      → 图库多选（PhotoViewPicker）
      → OCR（Kit 优先，MCP 兜底）
      → DeepSeek 生成结构化笔记
      → 预览确认
  → L3 写 RDB（事务 + 幂等键）
  → L4 知识星系 / 卡片展示结果
```

分支：

- 只查不生成：`小艺 → 智能体 → 端插件 → 查 RDB → 返回`
- 单张拍照：`拍照 → OCR → 生成 → 落库`（不经过批量队列）

## 5. 画图草案

### 5.1 边界（4 个框）

1. **系统入口（小艺）**
2. **智能体（小艺开放平台）**
3. **应用进程（端能力）**
4. **数据与资产**

### 5.2 节点

| 框 | 节点 | 说明 |
|---|---|---|
| 系统入口 | 小艺语音 | 用户说话的地方 |
| 系统入口 | 卡片 | 结果与进度回显 |
| 智能体 | 意图理解 | 把一句话变成任务 |
| 智能体 | 任务规划 | 决定调用顺序 |
| 智能体 | 插件调用 | 端插件 / 云插件 / MCP |
| 应用进程 | 意图 Ability | 接收 Want，启动任务 |
| 应用进程 | 批处理队列 | 并发 2、逐条 checkpoint |
| 应用进程 | 图库适配 | Picker 多选 |
| 应用进程 | OCR 适配 | Kit / MCP 可替换 |
| 应用进程 | 生成适配 | DeepSeek |
| 应用进程 | 落库 | 事务 + 幂等 |
| 数据与资产 | RDB | 笔记、复习计划 |
| 数据与资产 | 知识星系 | 可视化 |
| 数据与资产 | 语义索引 | 文搜图（可选） |

### 5.3 连线（主链路）

```
小艺语音 → 意图理解 → 任务规划 → 插件调用 → 意图 Ability
意图 Ability → 批处理队列 → 图库适配
批处理队列 → OCR 适配 → 生成适配 → 落库 → RDB
RDB → 知识星系
RDB → 卡片
```

虚线（可选/后续）：`OCR 适配 → MCP 工具`、`语义索引 → 知识星系`。
